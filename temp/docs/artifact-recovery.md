# 产物下载恢复与未解决的上游问题

记录日期：2026-11-06。**服务侧有界恢复已实现，以下五个样本文件的上游问题仍未解决。**

## 当前策略

- 每次导出中，同一 Task 最多额外刷新一次清单；首次和恢复下载均不叠加传输层重试，每个文件最多恢复下载一次。
- 所有额外刷新和恢复下载共用 60 秒预算，可通过 `FLUX_ARTIFACT_RECOVERY_TIMEOUT_SECONDS` 配置。
- 原清单保存为 `manifest.json`，刷新成功后另存 `manifest-refreshed.json`。仍只下载原清单选中的路径，后续校验使用刷新清单。
- 大小或 SHA256 变化时在 `downloads.json` 中保存前后预期值；文件消失、持续校验失败、上游下载失败、刷新失败和超时分别记录。
- 权限拒绝、身份或路径不匹配、大小超限及本地写入失败不进入恢复。权限错误缺少 `msg` 时也不再误当作文件正文。
- 不绕过校验保存错误字节，不把刷新后的文件声称为原版本。
